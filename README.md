# Tic Tac Toe Game

## Overview
This is a simple Tic Tac Toe game that can be played by two players. The game features a restart button to reset the game state.

## Features
- Two-player gameplay
- Restart button to reset the game
- Simple and clean user interface

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/tic-tac-toe.git
   cd tic-tac-toe
   ```
2. Open `index.html` in your web browser.

## Usage
- Click on the cells to place your mark (X or O).
- The game will announce the winner or a draw.
- Click the Restart button to reset the game.
